# Code of Conduct

## Taxi-v3 Q-Learning Project

### 1. Our Commitment

We are committed to creating an open, welcoming, and inclusive environment for everyone participating in the Taxi-v3 Q-Learning project.

We believe that all contributors should be treated with respect, regardless of their background, experience, nationality, gender, religion, or personal characteristics.

Our goal is to encourage collaboration, learning, and responsible open-source development.

### 2. Expected Behavior

All contributors are expected to:

- Treat others with respect and kindness.
- Communicate professionally and constructively.
- Respect different opinions and experiences.
- Provide helpful feedback and accept constructive criticism.
- Support beginners and encourage learning.
- Respect the privacy and personal information of others.
- Follow ethical principles when developing and using artificial intelligence.

### 3. Unacceptable Behavior

The following behaviors are not tolerated:

- Discrimination based on personal characteristics.
- Harassment, bullying, or intimidation.
- Offensive or insulting comments.
- Sharing someone's private information without permission.
- Threats or aggressive behavior.
- Deliberately disrupting discussions or project development.

### 4. Responsible AI Development

This project is designed for educational purposes and demonstrates reinforcement learning using the Gymnasium Taxi-v3 environment.

Contributors should follow responsible AI development practices:

- Avoid introducing harmful or discriminatory functionality.
- Respect user privacy and data security.
- Clearly document changes to the algorithm.
- Avoid misleading claims about the project's capabilities.
- Encourage transparent and ethical use of AI technologies.

### 5. Reporting Violations

If you experience or observe behavior that violates this Code of Conduct, please report it privately to the project maintainer.

Reports will be reviewed respectfully and confidentially to the extent possible.

Project maintainer: Aliaskar01

GitHub: https://github.com/Aliaskar01

### 6. Enforcement

Project maintainers are responsible for maintaining a respectful environment.

Depending on the severity of a violation, appropriate actions may include:

- A warning.
- Removal of inappropriate comments or contributions.
- Temporary restrictions on participation.
- Permanent removal from project collaboration.

### 7. Scope

This Code of Conduct applies to all project-related activities, including:

- GitHub Issues.
- Pull Requests.
- Code reviews.
- Project discussions.
- Communication between contributors.

### 8. Conclusion

By participating in this project, contributors agree to follow these guidelines.

We aim to maintain a safe, respectful, and inclusive environment where everyone can learn, collaborate, and contribute to open-source development.
